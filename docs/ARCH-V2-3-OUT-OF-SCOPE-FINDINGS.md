# ARCH-V2-3 Out-of-scope Findings

The following are intentionally not implemented in this stage:

- ARCH-V2-4 External Action / Receipt redesign;
- Automation workflow, Planner, Scheduler or business requirement execution;
- WebGPT page exploration or real Prompt submission;
- RuntimeRegistry, Shared CodexHost, Codex protocol or Map redesign;
- Renderer full rewrite or new Conversation/Transcript/Task truth;
- automatic recovery hidden behind status/read/list names.

These are boundaries, not accepted product failures. They remain subject to the next explicitly authorized architecture stage.
